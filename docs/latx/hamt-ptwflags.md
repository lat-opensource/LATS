# HAMT PTW 权限与状态

`ptwflags` 按 guest 物理地址（GPA）索引，每个 4 KiB 页占一个字节。它描述的是
能否使用 HAMT 直映及其权限，而非 guest PTE 授予的权限。汇编 TLB 重填路径只通过
`ptwflags` 获取这部分信息，不读取保护原因，也不等待写侧的锁。

| 标记 | 含义 |
| --- | --- |
| `NOWRITE` | 不允许通过直映写入。 |
| `NOACCESS_MASK` | 不允许建立直映，例如 MMIO 页。 |
| `NO2M` | 存放在每个 1 MiB 组的第一个字节中，禁止建立覆盖该组的大页映射。 |

重填 2 MiB 大页时会检查两个 1 MiB 组各自的 `NO2M`。任一组禁止大页，就回退到
4 KiB 重填。按 4 KiB 页检查访问和写入权限时，使用的掩码不包含 `NO2M`。
guest 页表权限独立检查，见 [HAMT PLV](hamt-plv.md)。

## 固定容量

`ptwflags`、`ptwflagstat` 和 `ptwdata1m` 在启动时一次性分配，放在同一块映射中，
固定覆盖 `[0, 128 GiB)` 的 GPA。准备 guest RAM 后端时，`hamt_ptwflags_reserve()`
只检查所需 GPA 上界是否超过容量；超出时报告错误并退出，不扩容，也不搬迁表。
PCI hole 不预置权限，固定地址排除仍由汇编检查，实际的非 RAM 区域仍由内存拓扑标记。

## 写侧临界区

`ptwflagstat` 是独立的字节数组，记录 SMC 和 VGA 保护原因，第 7 位用作页锁。
SMC 和 VGA 写线程通过 CAS 获取页锁，在临界区内更新 `ptwflags` 权限和保护原因；
最后通过 release 写入发布新的原因位并释放页锁。撤销一种保护原因时，如果另一种
仍然有效，就必须保留 `NOWRITE`。C 页表遍历短暂持有页锁，只读取当前 4 KiB 页的
权限和原因，解锁后再判断。`NOACCESS` 优先；若是 `NOWRITE`，同时存在两种原因时
归为 SMC，仅有 VGA 原因时归为 VGA，未识别到原因时保留 `HAMT_PTW_ERROR_NOWRITE`。
仅因组级 `NO2M` 不能填入大页时，仍按原路径回退，不把其他页的保护原因归给当前页。
汇编重填只通过 CPU 状态中的 `ptwflags` 读取权限，不会获取页锁。

`ptwdata1m` 为每个 1 MiB 组保存一个 16 位条目。第 15 位是独立的组锁，同样通过
CAS 获取；低位记录 0 到 256 个 SMC 页，包含正在施加保护的页所预占的计数。
同时需要两把锁时，先获取页锁，再获取组锁；没有持组锁再获取页锁的路径。

- 启用 SMC 保护时，先在组锁内置位 `NO2M` 并预占计数，再发布 `NOWRITE`。
  更新页权限前可以先释放组锁，因为其他写线程仍能看到预占计数，不能清除 `NO2M`。
- 撤销 SMC 保护时，先放宽页权限，再在组锁内扣减计数并重新判断 `NO2M`。
  SMC 计数归零并不意味着一定能清除 `NO2M`，还要检查组内是否仍有阻止大页的页。
- VGA 和 MMIO 不修改 SMC 计数，但通过组锁协调页权限和 `NO2M` 的更新。
  MMIO 只更新权限标记，不获取页锁。收紧权限时先发布 `NO2M`，再更新页权限；
  放宽权限时先更新页权限，再按条件清除 `NO2M`。

写侧内存屏障保证权限的发布顺序。这些锁不会使已有的 TLB 条目失效，也不能保证
已经开始的重填看到新权限。调用方仍须执行对应的 TLB 无效化流程。例如，SMC 权限
保护会在调用 `hamt_protect_code()` 前发布。

## VGA 脏页快照

启用 VGA 脏页跟踪时，`cpu_physical_memory_snapshot_and_clear_dirty()` 先重置软件
TLB 的脏页跟踪状态，再采集 VGA 快照，最后对该范围重新启用 VGA 保护。采集时逐页
获取页锁，将该页的保护原因位和禁止访问位合并保存；快照不保存锁位。VGA 快照使用
普通 RAM 脏位图之后的独立区域，按相对于快照起始 GPA 页的偏移索引，每页一个字节。
VGA 查询先将设备内偏移加上 VRAM 的 GPA 基址，再查快照；字节值为 0 表示脏页，
超出快照覆盖范围也按脏页处理。

首次写入会清除 VGA 原因。如果该页仍受 SMC 保护，写入路径保留 `NOWRITE`；
否则撤销写入限制，并按需重新判断 `NO2M`。快照只保证单页读取一致，不是整个范围的
原子快照；采集快照和重新启用保护也是两个独立调用。

主要实现见 `target/i386/hamt/hamt-ptw-flags.c`。VGA 调用方和首次写入路径分别位于
`softmmu/physmem.c` 和 `accel/tcg/cputlb.c`。
